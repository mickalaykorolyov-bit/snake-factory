# Claude sprite atlases

This folder contains the source PNG atlases and animation frame metadata extracted losslessly from the embedded assets in `index.html`.

The current demo runs directly from `index.html` and does not require external assets. Files in `assets/` are supplied for future editing and migration to separate asset loading.

Sprite atlas + JSON pairs: `head`, `body`, `modules`, `small`, `medium`, `heavy`, `boss`.
Floor images: `floor`, `floor2`, `floor3`, `floor_panel`.

Source: Claude `SNAKE_FACTORY_HANDOFF.zip` adapted for the Snake Factory prototype.
